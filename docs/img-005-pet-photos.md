# IMG-005 — Demo pet photographs

24 photographs, one per report except `report-001` which needs two, and
`report-009` which needs none (it is the scam report, filed with no photo —
leave it empty, that is the point of it).

**Format:** landscape 4:3, 800x600 is plenty. They are displayed at card size
(~390px) and up to 830px on a report page.

**Rules:** no identifiable people; these are fictional demo animals. Ordinary
phone-quality snapshots look more believable here than studio photography —
these are meant to look like pictures a worried owner had on their phone.

## The four pairs that matter most

Four pairs of reports describe the same animal from both sides. If these do not
look convincingly alike, the matching demo falls flat.

- **PAIR A — must look like the same dog.** Linked match, 85%. The demo centrepiece.
- **PAIR B — must look like the same dog.** Deliberately unlinked; the algorithm finds these at 100%.
- **PAIR C — must look like the same cat.** The completed reunion story.
- **PAIR D — should look similar but NOT identical.** A 75% match that is genuinely uncertain.
